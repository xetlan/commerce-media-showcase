What Merchandising does NOT do well here — be honest

This page pushed Merchandising to its limit. Below that limit are real gaps DXA and PA fill.
  • No experience metrics — no Frustration Score, no hesitation, no rage-click signals on a product's PDP. DXA territory.
  • No identity stitching across sessions — Merchandising is session-anchored. PA's cross-device user model isn't there.
  • No behavioral cohort definition from arbitrary event combinations — segments are catalog-derived (brand, category, price band) or basic ecommerce-event-based, not full-property cohorts.
  • No audience destinations — product-affinity cohorts can be exported manually but don't auto-sync to Meta / Google / CRM.
  • No A/B variant analysis on creative or copy — Merchandising is about which products sell, not which creatives or page layouts sell them.
  • No multi-touch attribution — revenue is attributed last-click to the order, not distributed across exposures.
  • No predictive scoring per user — Merchandising scores products, not customers.
  • Requires a paid add-on — Merchandising is metered separately from DXA, and Competitive Data / Visual Merchandising are further add-ons on top.

If you tried to build this via Contentsquare MCP today

Honest read on what's actually queryable from the current MCP server, separate from what Merchandising itself produces.
  • The Contentsquare MCP does not expose the Merchandising module at all. No product-level metrics, no catalog, no variant rollups, no category share, no cross-sell, no stock-revenue-loss queries.
  • What MCP could approximate on a properly-instrumented project: page-group level metrics for product PDPs (if every product had its own page group — impractical at scale); a funnel through Reached PDP → Reached Cart → Reached Order Received; Impact Quantification of one segment vs another on a conversion goal.
  • What MCP cannot approximate even in principle: brand-share rollups, SKU-level variant comparison, product opportunity buckets, stock revenue loss, cross-sell affinity, Visual Merchandising zone-product joins. All of these require Merchandising's catalog + ecommerce-API join, which has no MCP surface.
  • For this dashboard to become MCP-queryable, Contentsquare would need to add: (1) catalog product lookup endpoint, (2) per-SKU metrics endpoint with brand/variant/category dimensions, (3) opportunity-bucket retrieval, (4) stock-aware demand-modeling endpoint, (5) cross-sell affinity query. None exist today. Track via the repo if/when that changes.
